Ja. **-vis** er en ganske produktiv endelse i norsk, ofte med betydningen «på en bestemt måte», «gradvis» eller «med hensyn til». Mange slike ord er særlig nyttige fra **B1–B2**.

Her er en CEFR-inndelt liste, med omtrentlige nivåer:

### A1

| Ord           | Betydning                   |
| ------------- | --------------------------- |
| **vanligvis** | usually                     |
| **særlig**    | especially / particularly   |
| **muligvis**  | possibly                    |
| **heldigvis** | fortunately                 |
| **dessverre** | unfortunately *(ikke -vis)* |

**Vanligvis** er klart det viktigste -vis-ordet på A1/A2.

### A2

| Ord               | Betydning                             |
| ----------------- | ------------------------------------- |
| **heldigvis**     | fortunately                           |
| **tydeligvis**    | apparently / evidently                |
| **naturligvis**   | naturally / of course                 |
| **sannsynligvis** | probably                              |
| **muligvis**      | possibly                              |
| **gradvis**       | gradually                             |
| **delvis**        | partly                                |
| **visstnok**      | supposedly / apparently *(ikke -vis)* |

Eksempel:

> Han kommer **sannsynligvis** i morgen.
> Prisene har økt **gradvis**.

### B1

| Ord                | Betydning                                        |
| ------------------ | ------------------------------------------------ |
| **henholdsvis**    | respectively                                     |
| **individuelt**    | individually *(ikke -vis)*                       |
| **midlertidigvis** | temporarily *(uvanlig; normalt: midlertidig)*    |
| **alternativvis**  | alternatively *(sjeldent; normalt: alternativt)* |
| **enkeltvis**      | individually / one at a time                     |
| **parvis**         | in pairs                                         |
| **gruppevis**      | in groups                                        |
| **trinnvis**       | step by step                                     |
| **fortløpende**    | continuously / on an ongoing basis *(ikke -vis)* |
| **vanligvis**      | usually                                          |

**Henholdsvis** er spesielt viktig å lære på B1/B2:

> Norge og Sverige har henholdsvis 5,6 og 10,6 millioner innbyggere.

= Norway and Sweden have **5.6 and 10.6 million inhabitants, respectively**.

### B2

Her blir -vis-ordene mer abstrakte og formelle:

| Ord                | Betydning                               |
| ------------------ | --------------------------------------- |
| **vesentligvis**   | essentially / substantially             |
| **hovedsakelig**   | mainly / primarily *(ikke -vis)*        |
| **utelukkende**    | exclusively *(ikke -vis)*               |
| **forholdsvis**    | relatively                              |
| **tilsynelatende** | apparently / seemingly *(ikke -vis)*    |
| **bokstaveligvis** | literally *(normalt: bokstavelig talt)* |
| **prosentvis**     | percentage-wise / in percentage terms   |
| **tallmessig**     | numerically *(ikke -vis)*               |
| **forholdsvis**    | relatively                              |
| **enkeltvis**      | individually                            |
| **trinnvis**       | stepwise                                |
| **gradvis**        | gradually                               |

Eksempler:

> Dette er **forholdsvis** enkelt.
> Arbeidet skal gjennomføres **trinnvis**.
> Lønningene har økt **prosentvis** mer enn prisene.

### C1–C2

På høyere nivå møter du mange mer formelle og spesialiserte ord:

| Ord                               | Betydning                      |
| --------------------------------- | ------------------------------ |
| **indirekte**                     | indirectly                     |
| **kollektivt / gruppevis**        | collectively / by groups       |
| **individvis**                    | individually, person by person |
| **punktvis**                      | point by point / locally       |
| **leddvis**                       | component by component         |
| **årvis**                         | year after year                |
| **månedsvis**                     | month by month                 |
| **ukevis**                        | for weeks at a time            |
| **dagvis**                        | for days at a time             |
| **vis** / **vis**-sammensetninger | in a particular manner         |

For eksempel:

> Pasientene ble undersøkt **enkeltvis**.
> Problemene ble løst **trinnvis**.
> Temperaturen sank **gradvis**.
> Han hadde vært syk **ukevis**.

### ⭐ De viktigste å kunne til Norskprøven

Hvis målet ditt er Norskprøven, ville jeg prioritert disse:

**A1–A2**

* vanligvis
* heldigvis
* dessverre
* sannsynligvis
* tydeligvis
* naturligvis
* gradvis
* delvis

**B1**

* henholdsvis
* enkeltvis
* parvis
* gruppevis
* trinnvis

**B2**

* forholdsvis
* prosentvis
* vesentligvis
* punktvis

Et nyttig mønster å lære er:

> **-vis = på en bestemt måte / én etter én / grad for grad**

Derfor får du f.eks.:

* **parvis** = par + vis → to og to
* **gruppevis** = gruppe + vis → gruppe for gruppe
* **enkeltvis** = enkelt + vis → én om gangen
* **trinnvis** = trinn + vis → trinn for trinn
* **gradvis** = grad + vis → grad for grad
* **prosentvis** = prosent + vis → målt i prosent
* **forholdsvis** = forhold + vis → relativt sett

Merk at **ikke alle ord som slutter på -vis har samme betydning**, og noen former som *alternativvis* og *midlertidigvis* er lite naturlige i moderne norsk.
