Ja! Det finnes flere uttrykk med **«… som helst»**. De er veldig nyttige i norsk.

### De vanligste

| Uttrykk               | Betydning            | Eksempel                                  |
| --------------------- | -------------------- | ----------------------------------------- |
| **hva som helst**     | anything             | Du kan spørre om **hva som helst**.       |
| **hvem som helst**    | anyone               | **Hvem som helst** kan lære dette.        |
| **hvor som helst**    | anywhere             | Du kan sitte **hvor som helst**.          |
| **når som helst**     | anytime              | Du kan ringe meg **når som helst**.       |
| **hvordan som helst** | however / in any way | Du kan gjøre det **hvordan som helst**.   |
| **hvilken som helst** | any (one)            | Du kan velge **hvilken som helst** bok.   |
| **hvilket som helst** | any (neuter)         | Du kan velge **hvilket som helst** språk. |
| **hvilke som helst**  | any (plural)         | Du kan velge **hvilke som helst** bøker.  |

### Hva betyr «som helst»?

**som helst** gir betydningen **«det spiller ingen rolle hvilken/hvem/hva/når/hvor»**.

For eksempel:

* **hva som helst** = det spiller ingen rolle **hva**
* **hvem som helst** = det spiller ingen rolle **hvem**
* **hvor som helst** = det spiller ingen rolle **hvor**
* **når som helst** = det spiller ingen rolle **når**
* **hvordan som helst** = det spiller ingen rolle **hvordan**

### «Hvilken som helst» er spesielt nyttig

Her må **hvilken/hvilket/hvilke** passe med substantivet:

* **hvilken som helst bil** 🚗
* **hvilket som helst hus** 🏠
* **hvilke som helst bøker** 📚

For eksempel:

> Du kan velge **hvilken som helst dag**.

= You can choose **any day**.

> Du kan bruke **hvilket som helst program**.

= You can use **any program**.

> Du kan stille **hvilke som helst spørsmål**.

= You can ask **any questions**.

**Kort sagt:**
**hva, hvem, hvor, når, hvordan, hvilken/hvilket/hvilke + som helst** er en veldig nyttig gruppe å lære sammen.

Relating to this:

Ja! Disse ordene følger et ganske fint mønster på norsk:

| English        | Norsk                             | Eksempel                              |
| -------------- | --------------------------------- | ------------------------------------- |
| **anywhere**   | **hvor som helst**                | Du kan sitte **hvor som helst**.      |
| **everywhere** | **overalt**                       | Det er snø **overalt**.               |
| **somewhere**  | **et sted / et eller annet sted** | Hun bor **et sted** i Oslo.           |
| **anytime**    | **når som helst**                 | Du kan ringe meg **når som helst**.   |
| **every time** | **hver gang**                     | Hun smiler **hver gang** hun ser ham. |
| **sometime**   | **en gang / på et tidspunkt**     | Vi kan møtes **en gang** neste uke.   |

### Et viktig mønster

**any-** → **hvor/når som helst**

* anywhere → **hvor som helst**
* anytime → **når som helst**

**every-** → **over-/hver**

* everywhere → **overalt**
* every time → **hver gang**

**some-** → **et sted / en gang**

* somewhere → **et sted**
* sometime → **en gang**

⚠️ På engelsk er **every time** vanligvis skrevet som **to ord**.
**Everytime** er ikke standard engelsk.

### Sammenlign

* **You can go anywhere.** → Du kan dra **hvor som helst**.
* **I looked everywhere.** → Jeg lette **overalt**.
* **He is somewhere in Oslo.** → Han er **et sted i Oslo**.
* **Call me anytime.** → Ring meg **når som helst**.
* **Every time I see her, she smiles.** → **Hver gang** jeg ser henne, smiler hun.
* **Let's meet sometime next week.** → La oss møtes **en gang neste uke**.

Et lite tips: **«som helst» betyr omtrent «no matter which/when»**, så **hvor som helst** = *anywhere*, og **når som helst** = *anytime*.
