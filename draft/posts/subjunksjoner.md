level: B1 B2

# subjunksjoner (subordinating conjunctions)

They introduce a **leddsetning** (subordinate clause), where **ikke** normally comes before the finite verb.

## Common subjunksjoner

### Time

| Norwegian    | English     |
| ------------ | ----------- |
| når          | when        |
| da           | when (past) |
| mens         | while       |
| før          | before      |
| etter at     | after       |
| siden        | since       |
| så snart som | as soon as  |
| inntil       | until       |

Examples:

> Når det **ikke er** kaldt, går vi tur.

> Mens hun **ikke er** hjemme, passer jeg katten.

---

### Condition

| Norwegian | English    |
| --------- | ---------- |
| hvis      | if         |
| dersom    | if         |
| om        | if/whether |

Examples:

> Hvis det **ikke regner**, går vi ut.

> Om du **ikke kan** komme, må du si fra.

---

### Cause / Reason

| Norwegian  | English                 |
| ---------- | ----------------------- |
| fordi      | because                 |
| siden      | since/because           |
| ettersom   | since/as                |
| fordi at\* | because (_less formal_) |

Examples:

> Jeg ble hjemme fordi jeg **ikke følte** meg bra.

> Siden han **ikke har** tid, kommer han ikke.

---

### Contrast / Concession

| Norwegian   | English     |
| ----------- | ----------- |
| selv om     | although    |
| skjønt      | although    |
| enda        | even though |
| selv dersom | even if     |

Examples:

> Selv om det **ikke er** varmt, bader jeg.

> Skjønt jeg **ikke liker** kaffe, drikker jeg det av og til.

---

### Purpose

| Norwegian | English |
| --------- | ------- |
| for at    | so that |
| slik at   | so that |
| så        | so that |

Examples:

> Jeg snakker sakte slik at du **ikke skal** misforstå.

---

### Result

| Norwegian | English     |
| --------- | ----------- |
| så ... at | so ... that |

Example:

> Det var så kaldt at vi **ikke gikk** ut.

---

### Comparison

| Norwegian | English |
| --------- | ------- |
| som       | as      |
| enn       | than    |

Examples:

> Hun er eldre enn jeg **trodde**.

> Han er flinkere enn han **selv tror**.

---

### Content Clauses

| Norwegian | English    |
| --------- | ---------- |
| at        | that       |
| om        | whether/if |

Examples:

> Jeg vet at han **ikke kommer**.

> Jeg vet ikke om han **kommer**.

---

## Easy rule for B1–B2

If you see one of these words introducing a clause:

> **at, om, hvis, dersom, fordi, siden, ettersom, når, da, mens, før, etter at, inntil, selv om, skjønt, for at, slik at**

then expect the subordinate-clause word order:

> **subjunksjon + subject + ikke + verb**

Examples:

> fordi han **ikke er** hjemme

> hvis vi **ikke kan** komme

> når det **ikke regner**

> selv om hun **ikke liker** fisk

A classic Norwegian mnemonic is:

> **"Ikke kommer før verbet i leddsetninger."**

That's one of the most important word-order rules in Norwegian.
