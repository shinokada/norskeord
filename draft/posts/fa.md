
# få-verbs


# 🧠 1. **få tak i** = get hold of / reach

👉 You already saw this:

* Jeg må **få tak i henne** = I need to reach her
* Jeg får ikke **tak i henne** = I can’t reach her

✔ Used for people or things you try to obtain/contact.

---

# 🧠 2. **få til** = manage / succeed in doing something

👉 This is one of the most important B1–B2 verbs.

* Jeg får det til = I manage it
* Jeg får det ikke til = I can’t manage it

### Examples:

* Jeg får ikke **til** å lære norsk
* Klarer du å **få det til**?
* Hun får alt til = She manages everything

👉 Think: **“I succeed in doing it”**

---

# 🧠 3. **få på** = get something on (clothes, objects)

👉 You already learned this one:

* Jeg får jakken på = I manage to put the jacket on
* Jeg får den ikke på = I can’t get it on

👉 Think: **put on successfully**

---

# 🧠 4. **få i gang** = get started / activate

👉 Means: start something that is inactive

* Vi må få i gang prosjektet = start the project
* Han fikk maskinen i gang = he got the machine running
* Jeg fikk ikke PC-en i gang = I couldn’t start the PC

👉 Think: **“make it start working”**

---

# ⚖️ Quick comparison

| Expression | Meaning             |
| ---------- | ------------------- |
| få tak i   | reach / get hold of |
| få til     | manage / succeed    |
| få på      | put on              |
| få i gang  | start / activate    |

---

# 🔥 Simple memory trick

* **tak i** → grab/reach someone
* **til** → achieve something
* **på** → put on something
* **i gang** → get something running

---

# 🧠 Real-life mini story

* Jeg må **få tak i** læreren
* Jeg prøver å **få til** leksene
* Jeg får ikke jakken **på**
* Vi må **få i gang** møtet
