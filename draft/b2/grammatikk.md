## Substantivfrasen og substantiverte adjektiv
### Substantivfrasens struktur
| bestemmer | beskriver  | substantiv | bestemmer | beskriver            |
| --------- | ---------- | ---------- | --------- | -------------------- |
| et        |            | språk      |           |                      |
|           | snille     | barn       |           |                      |
|           |            | jobben     | til Lars  |                      |
|           |            | svar       |           | på søknaden          |
|           |            | eplene     |           | som er på tilbud     |
| et        | vanskelig  | språk      |           |                      |
| mange     |            | barn       |           | som er veldig snille |
|           | positiv    | svar       |           | på søknaden          |
| fire      | vanskelige | spørsmål   |           | fra læreren          |
| de        | gode       | eplene     |           | som er på tilbud     |

### substantiverte adjektiv
|          | entall ubestemt form | entall bestemt form | flertall ubestemt form | fletall bestmt form |
| -------- | -------------------- | ------------------- | ---------------------- | ------------------- |
| voksen   | en voksen            | den voksene         | mange voksne           | de voksne           |
| størst   | -                    | den største         | -                      | de største          |
| ansatt   | en ansatt            | den ansatte         | fem ansatte            | de ansatte          |
| reisende | en reisende          | den reisende        | alle reisende          | de reisende         |

suffiksene: avledninger som vi legger til bak et ord


prefikser 
u-,mis-,for-
lykke -> ulykke
arbeide -> samarbeide
forstå -> miforstå
...

suffiksene
adjektiv: -lig, -som, -iv
substantiv: -nad, -ing/ning, -er, -het, -sjon, -else
verb: -ere

kjærlig, kjærlighet, lykkelig
søknad, lykkelig, produksjon, produktiv

ordfamilier
