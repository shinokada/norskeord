## A1 — Beginner

> Current gap: entirely noun-heavy; no dedicated descriptive adjectives or core verbs.

### New categories

- [x] **basic adjectives** — Size, age, quality, feelings: _stor, liten, ny, gammel, god, dårlig, varm, kald, glad, lei seg, trøtt, sulten_
- [x] **basic verbs** — Core action verbs: _å være, å ha, å gå, å spise, å drikke, å sove, å snakke, å se, å høre, å komme_
- [x] **pronouns & questions** — Foundational grammar vocab: _jeg, du, han, hun, vi, de, hva, hvor, hvem, når, hvorfor, hvordan_
- [x] **feelings (basic)** — Simple emotional states: _glad, lei seg, sint, redd, overrasket, rolig, nervøs, trist_
- [x] **weather (basic)** — Essential small-talk in Norway: _sol, regn, snø, vind, kaldt, varmt, overskyet, tordenvær_
- [x] **transportation (basic)** — Very simple travel vocab (A2 transport goes deeper): _buss, tog, bil, sykkel, båt, fly, til fots, stasjon_
