# SEO todos

- Inbound links — even one or two links from credible Norwegian learning communities (Reddit r/norsk, Norwegian language forums, NorskForDeg etc.) would help more than any meta tag change.
- Google Search Console verification — if you've submitted the sitemap and claimed ownership, Google will eventually index the brand name. Check GSC's Coverage report to see what's indexed.
- Time — for a brand query on your own domain name, this usually resolves within a few months of GSC submission + some backlinks.
