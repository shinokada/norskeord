> **TL;DR:** A **subjunksjon** introduces a subordinate clause and triggers a word-order change — sentence adverbs like **ikke** move in front of the finite verb. Learning to recognise these words is key to reading and writing longer Norwegian sentences.

## Kort forklaring

En **subjunksjon** innleder en **leddsetning** (subordinate clause). Når en subjunksjon starter en klausul, bytter setningsadverbet (som **ikke**, **aldri**, **alltid**) plass og kommer foran det finitte verbet.

**Hovedsetning:** Han **er ikke** hjemme.
**Leddsetning:** … fordi han **ikke er** hjemme.

_In English:_ Subordinating conjunctions work similarly to English — "because," "if," "when," "although" — but they trigger a strict word-order rule in Norwegian that doesn't exist in English.

---

## Ordstillingsregelen

Husk dette mønsteret:

> **subjunksjon + subjekt + ikke/adverb + verb + ...**

| Subjunksjon | Subjekt | Adverb | Verb   | Resten |
| ----------- | ------- | ------ | ------ | ------ |
| fordi       | han     | ikke   | er     | hjemme |
| hvis        | vi      | ikke   | kan    | komme  |
| når         | det     | ikke   | regner | —      |
| selv om     | hun     | ikke   | liker  | fisk   |

## Tid — Time

Brukes om når noe skjer i forhold til noe annet.

| Subjunksjon  | Engelsk     |
| ------------ | ----------- |
| **når**      | when        |
| **da**       | when (past) |
| **mens**     | while       |
| **før**      | before      |
| **etter at** | after       |
| **siden**    | since       |
| **så snart** | as soon as  |
| **inntil**   | until       |

**Eksempler:**

**Når det ikke er kaldt, går vi tur.**
_When it isn't cold, we go for a walk._

**Mens hun ikke er hjemme, passer jeg katten.**
_While she isn't home, I'm looking after the cat._

**Da han ikke kom, dro vi uten ham.**
_When he didn't come, we left without him._
→ **Da** brukes om fortiden; **når** brukes om nåtid og fremtid.

---

## Betingelse — Condition

Brukes om noe som er betinget av noe annet.

| Subjunksjon | Engelsk      |
| ----------- | ------------ |
| **hvis**    | if           |
| **dersom**  | if           |
| **om**      | if / whether |

**Eksempler:**

**Hvis det ikke regner, går vi ut.**
_If it doesn't rain, we'll go out._

**Om du ikke kan komme, må du si fra.**
_If you can't come, you need to let us know._

→ **Hvis** og **dersom** er utbyttbare i de fleste sammenhenger. **Dersom** er litt mer formelt.

---

## Årsak — Cause / Reason

Brukes for å forklare hvorfor noe skjer.

| Subjunksjon  | Engelsk         |
| ------------ | --------------- |
| **fordi**    | because         |
| **siden**    | since / because |
| **ettersom** | since / as      |

**Eksempler:**

**Jeg ble hjemme fordi jeg ikke følte meg bra.**
_I stayed home because I didn't feel well._

**Siden han ikke har tid, kommer han ikke.**
_Since he doesn't have time, he isn't coming._

→ **Siden** er flertyddig: det kan bety «since» (tid) eller «since/because» (årsak). Konteksten avgjør.

---

## Kontrast — Contrast / Concession

Brukes når noe er sant til tross for noe annet.

| Subjunksjon     | Engelsk     |
| --------------- | ----------- |
| **selv om**     | although    |
| **skjønt**      | although    |
| **enda**        | even though |
| **selv dersom** | even if     |

**Eksempler:**

**Selv om det ikke er varmt, bader jeg.**
_Although it isn't warm, I'm swimming._

**Skjønt jeg ikke liker kaffe, drikker jeg det av og til.**
_Although I don't like coffee, I drink it occasionally._

→ **Selv om** er langt vanligere enn **skjønt** i dagligtale. **Skjønt** er mer skriftlig og formelt.

---

## Hensikt — Purpose

Brukes for å forklare hensikten med noe.

| Subjunksjon | Engelsk |
| ----------- | ------- |
| **for at**  | so that |
| **slik at** | so that |

**Eksempler:**

**Jeg snakker sakte slik at du ikke skal misforstå.**
_I speak slowly so that you won't misunderstand._

**Han jobbet hardt for at familien ikke skulle lide.**
_He worked hard so that his family wouldn't suffer._

---

## Resultat — Result

| Subjunksjon | Engelsk   |
| ----------- | --------- |
| **så … at** | so … that |

**Eksempel:**

**Det var så kaldt at vi ikke gikk ut.**
_It was so cold that we didn't go out._

---

## Innhold — Content Clauses

Brukes for å introdusere en setning som fungerer som objekt eller subjekt.

| Subjunksjon | Engelsk      |
| ----------- | ------------ |
| **at**      | that         |
| **om**      | whether / if |

**Eksempler:**

**Jeg vet at han ikke kommer.**
_I know that he isn't coming._

**Jeg vet ikke om han kommer.**
_I don't know whether he's coming._

→ **Om** i innholdssetninger betyr «whether/if», ikke «if» som betingelse.

## Vanlige feil

❌ fordi han er ikke hjemme
⭕ fordi han **ikke er** hjemme

_I leddsetninger kommer **ikke** foran det finitte verbet._

❌ hvis vi kan ikke komme
⭕ hvis vi **ikke kan** komme

_Samme regel: **ikke** foran verbet i leddsetningen._

❌ Da vi reiser til Oslo, …
⭕ **Når** vi reiser til Oslo, …

_**Da** brukes om konkrete fortidshendelser. For nåtid og fremtid er **når** riktig._

---

## Husk dette

- Subjunksjoner innleder leddsetninger og utløser ordstillingsregel
- **subjunksjon + subjekt + ikke/adverb + verb**
- **Da** = when (past, specific); **når** = when (present / future / repeated)
- **Om** kan bety «if» (betingelse) eller «whether» (innhold) — kontekst avgjør
- **Siden** kan bety «since» (tid) eller «because» (årsak) — kontekst avgjør
